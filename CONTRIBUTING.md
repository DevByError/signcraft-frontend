# Contributing

Thanks for taking the time to help. This is a small project, so the process is simple.

1. Open an issue first for anything larger than a small fix, so we can agree on the approach.
2. Fork the repository and create a branch from `main`.
3. Keep each pull request focused on one change.
4. Make sure the project builds before you open the pull request (see the README for the commands).
5. Write commit messages in the imperative mood, for example "Fix playlist duration rounding".

Please do not commit `.env` files, API keys, uploaded media or database dumps.
